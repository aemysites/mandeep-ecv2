# Hero Banner Block

A full-width banner with background image and title overlay, styled for pharmaceutical content.

## Features
- Full-width teal background with optional background image
- Centered title with white text
- Responsive layout
- Optional subtitle text

## Usage

```markdown
+----------------------------------------------------------+
| **Hero-Banner**                                          |
+----------------------------------------------------------+
| ![Background](./images/hero-bg.png)                      |
+----------------------------------------------------------+
| ## Dosing & Administration                               |
+----------------------------------------------------------+
```

## Example with No Image

```markdown
+----------------------------------------------------------+
| **Hero-Banner**                                          |
+----------------------------------------------------------+
| ## Page Title                                            |
| Optional subtitle text                                   |
+----------------------------------------------------------+
```

## CSS Variables Used
- `--lokelma-green`: Background color (#00927c)
- `--lokelma-blue`: Alternative background (#003b45)
